# Contrat des modes regroupé par thème

`PageModeDefinition` est un ensemble plat de 32 membres optionnels, dont plusieurs n'ont qu'un seul utilisateur. Le
regrouper par thème (cycle de vie, flèches, formes, parties, interface), au moment où un troisième mode arrive :
renommer aujourd'hui casserait les deux modes pour un gain théorique. La table des garanties (292) donne déjà ces
thèmes.

Autre piste, à surveiller : les régions RDD (contenu calculé, agrandissement, obstacles entre sœurs) sont un
conteneur logique générique ; les remonter dans le tronc au deuxième mode qui en a besoin.
