# Event storming : zones de placement au glisser, échange en lâchant sur un autre

> Mode Event storming (475) ; dépend de 477 (aimantation, gestes du mode)

- En glissant un post-it, voir les places où il peut aller selon son type (grammaire de l'event storming, ex. une
  Command à droite d'un Actor, un Domain Event à droite d'une Command, une Policy sous un Domain Event…).
- Lâché sur un autre post-it : les deux échangent leur place.
- À préciser : la grammaire exacte (quel type à côté de quel type, par quel côté), l'aspect des zones, ce que fait un
  post-it lâché hors d'une zone.
